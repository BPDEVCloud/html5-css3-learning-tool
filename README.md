# HTML5 & CSS3 Learning Tool

A beginner-friendly Python project for exploring modern HTML5 and CSS3 concepts through interactive lessons, examples, and quick quizzes.

## What you will learn
- HTML5 semantic structure and accessibility
- Form improvements and media elements
- CSS3 styling foundations
- Flexbox and Grid layouts
- Responsive design and animations
- Best practices for modern web pages

## Project structure
- `app.py` – interactive learning script
- `README.md` – project overview and instructions
- `lessons/` – lesson notes and explanations
- `examples/` – sample HTML and CSS files
- `requirements.txt` – optional dependencies (currently empty for standard-library setup)

## Run the app
```bash
python app.py
```

## Example workflow
1. Launch the app.
2. Select a lesson number.
3. Review the explanation and code sample.
4. Try the quiz to test your understanding.
5. Open the sample files in `examples/` to see real implementations.

## Recommended learning order
1. HTML5 Basics
2. CSS3 Basics
3. Layouts and Responsiveness
4. Advanced Features

## Files included
- `lessons/html5_basics.md`
- `lessons/css3_basics.md`
- `lessons/layouts_and_responsiveness.md`
- `lessons/advanced_features.md`
- `examples/sample_page.html`

## Notes
This project is intentionally lightweight and uses only Python's built-in modules so it runs without additional installation.
